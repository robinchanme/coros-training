## 确认官方版存在并完成差异化改造

**调研结论（决定项目定位的关键事实）：**
- WorkBuddy 市场已有官方连接器「高驰」（source=`coros`），描述为「用自然语言查询 COROS 运动与健康数据：训练记录、活动分析、睡眠、心率、HRV、压力、体能评估与训练日程」——**纯只读**。
- 高驰官方 MCP 于 2026-09-21 新增「创建/修改训练计划与课程并同步到 COROS」能力，官方市场版**尚未跟进**。这就是本项目的差异化缺口。
- 官方 MCP 工具共 20+ 个，本项目 Skill 全量覆盖，含 9 项写入工具（createTrainingPlan / updateTrainingPlan / createSingleWorkout / updateWorkoutDetails / scheduleWorkout / createScheduledWorkout / queryScheduledWorkoutDetails / updateScheduledWorkout / queryTrainingPlanLibrary + queryTrainingPlanDetails）。
- 官方硬限制（不可打开的开关）：无 Webhook、无 GPX 导入导出、运动记录不可双向同步、独立日程移动/删除与计划退出需在 COROS App 完成、新建结构化课程仅支持跑步(1)/骑行(2)/越野(5)、休息日(4)、FIT 下载 50 个/24h。

**本次改造：**
- `connector-meta.json`：`source` 由 `coros` 改为 `coros-training`；name 改「高驰训练」/COROS Training；描述改写为强调写入链路；examples 扩到 6 条、加入「把上周那节阈值间歇课改到这周四」「练得是不是太多了」。
- `skills/coros/` → `skills/coros-training/`，SKILL.md frontmatter 的 name/display_name 同步更新。
- SKILL.md 第 20 行加防混淆提示：用户可能同时装了官方只读版，写入工具不存在时不要用只读工具模拟写入。
- README 新增「与市场已有连接器的区别」章节（9 行能力对照表）。
- 重新打包 `/Users/binson/project/coros-training-connector-1.0.0.zip`（17.6 KB / 9 条目），敏感信息扫描通过。旧的 `coros-connector-1.0.0.zip` 作废。
